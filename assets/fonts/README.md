# Fontes locais

Estas são as fontes canônicas usadas pelo candidato V0.1. O site não depende de fontes
instaladas na máquina nem de carregamento remoto.

- **Display:** Familjen Grotesk, pesos 600 e 700 (`familjen-grotesk-600.ttf` e
  `familjen-grotesk-700.ttf`).
- **Corpo:** Archivo, pesos 400–900 e itálicos 400–900 (`archivo-v25-*.ttf`).
- `archivo-700.ttf` é a cópia histórica usada pelo card social; o runtime usa
  `archivo-v25-700.ttf` como fonte Archivo 700 canônica.

Os tokens ativos em `_ds/ligou-design-system-a33905fc-3bee-481b-b797-48c2b57eab4c/`
definem Familjen para display e Archivo para corpo. Isso está implementado neste
candidato V0.1; a aprovação do sistema de marca continua sendo uma decisão distinta.

As licenças correspondentes acompanham as famílias em `OFL-Archivo.txt` e
`OFL-Familjen-Grotesk.txt`.
