## Custody

- Dashboard uses PKCE (`flowType: "pkce"`) with a custody storage: provider
  tokens are stripped from every persisted session, the PKCE verifier lives
  only in sessionStorage (which rejects session material), React state receives
  a provider-stripped session (raw tokens live only in a one-shot ref), and the
  post-handoff session rotation is awaited.
- `google-handoff` verifies caller JWT, tenant ownership by UUID, single-use
  intent (nonce hash), Google tokeninfo (audience, subject vs owner profile,
  email, both calendar scopes, expiry), encrypts with the existing AES-GCM
  envelope, proves decryption pre- and post-write, and discards raw tokens.
  Active connectors are preserved when no refresh token arrives; revoked or
  errored connectors are never reactivated by a plain login; every error fails
  closed with no calendar fallback.
