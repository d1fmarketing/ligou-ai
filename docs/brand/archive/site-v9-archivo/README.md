# Snapshot histórico — tipografia Archivo da V9

Esta pasta preserva os tokens Archivo-only de um snapshot V9 anterior. Ela não é
carregada pelo candidato V0.1 e não define a tipografia atual.

Os arquivos CSS abaixo foram mantidos como registro histórico. Seus `@font-face` apontam
para os arquivos canônicos em `assets/fonts/`, mas não devem ser copiados para o runtime
nem usados como instrução de implementação. O candidato V0.1 usa Familjen Grotesk
600/700 para display e Archivo para corpo nos tokens ativos do design system.
