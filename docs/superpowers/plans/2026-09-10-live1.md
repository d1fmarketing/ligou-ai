# Managed OpenAI migration — execution checklist

The current source of authority is [the managed migration goal](../../live1/IMPLEMENTATION-GOAL.md). It replaces the earlier client-delegation/subscription plan and optional Agents QA pilot. Historical experiments remain in Git; they are not active requirements.

## Architecture and boundaries

Voice: authenticated owner/browser → GPT-Live-1 → managed Responses delegation (`gpt-5.6-terra`, low reasoning initially) → scoped business tools → existing Supabase records. Native streamed audio, bossa initially, microphone active during speech. No fixed speech, TTS, MP3, external context preparer or Codex subscription adapter.

Async: authorized structured onboarding analysis of an already-collected source → Agents API managed session (one agent, no environment) → existing validated worker result contract. It does not recrawl or replace the selected result automatically. Private agents, remaining infrastructure, credentials and source data are preserved.

Current paid voice/reasoning/Agents authority applies; no unlimited spending, new credentials or account-limit increases. Internal human QA keeps its existing daily-budget exception and $7.50 per-call reservation / $6.50 soft limit. The two unanswered Agents task-cap and provider-state retention questions remain pending; they do not block independent voice delivery.
