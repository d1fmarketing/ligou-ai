# Handoff V0.1 — estado local do hardening

Este branch contém implementação e testes locais com identidades/credenciais sintéticas. Ele não está
implantado, não foi verificado ao vivo e não deve ser descrito como production-ready.

## Contratos atuais

- Supabase é a autoridade de tenant, poderes, regras, bookings, receipts e auditoria.
- Recursos Hermes são derivados do UUID imutável; o registro valida também o slug de exibição.
- Hermes de chamada recebe contexto estruturado e devolve somente um action code fechado. Aprendizado livre
  pós-chamada está desativado; calls pendentes viram `skipped` com motivo fixo para retenção.
- Calendar usa somente conector OAuth cifrado do tenant. Não existe fallback fake/gerenciado/plaintext.
- Backup/restore e release/rollback têm manifests autenticados, contenção e testes de falha locais.

## Evidência e limites

Suites locais isoladas, builds, Edge check congelado e secret scan são as evidências deste branch. Migrations,
Docker real, systemd, Linux flock, Google, OpenAI, Twilio, AWS, EC2, SSM, Vercel e produção Supabase não foram
exercitados nesta fase.
